# Массажный салон «Баланс» — мини-лендинг

Одностраничный лендинг для массажного салона с современным минималистичным дизайном.

## Содержание

- **Заголовок** — главный оффер и призыв к действию
- **Услуги** — карточки с описанием и ценами (расслабляющий массаж, антистресс, лимфодренаж)
- **Отзывы** — блок с отзывами клиентов
- **Контакты** — телефон, мессенджеры, адрес, график работы

## Технологии

- HTML5
- CSS3 (встроенные стили, CSS-переменные, Grid, Flexbox)
- Vanilla JavaScript (плавная прокрутка к секциям)

## Адаптивность

- **Десктоп** — полная версия с подробными текстами
- **Планшет** — двухколоночная сетка
- **Телефон** — крупные кнопки, сокращённый текст, одноколоночная вёрстка

## Запуск

Откройте `index.html` в браузере. Сервер не требуется — это статическая страница.

```bash
# или через локальный сервер (опционально)
python -m http.server 8000
# затем откройте http://localhost:8000
```

## Настройка

Чтобы подставить свои данные, отредактируйте `index.html`:

- Телефон: `+7 (999) 000‑00‑00` и ссылки `tel:`, `wa.me`
- Адрес и описание проезда
- Название салона, услуги, цены, отзывы
